## ✨ Features

### 🔍 Smart Search

-   Search by **title, author, ISBN, subject**
-   Filter by type, availability, subject, and year

### 👤 Student Features

-   View loans, due dates, renewals, reservations, fines

### 📋 Librarian Features

-   Manage books, ISBN lookup, circulation

### 🔧 Admin Features

-   System control, roles, settings
